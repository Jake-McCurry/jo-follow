---
name: FAQ message invitations
description: Editorial decision for revised Follow Jesus FAQ invitations to contact the team.
---

When FAQ source documents invite visitors to write a question, route them to the existing contact page rather than adding or implying an inline message box.

**Why:** The user approved this treatment for the revised FAQs because the contact page already has a Mailchimp-backed form; the DOCX copy refers to a nonexistent box below the answer.

**How to apply:** For future FAQ imports or editorial revisions, preserve the invitation while linking it to the site's contact page. Do not publish "write in the box below" without an actual inline form.
