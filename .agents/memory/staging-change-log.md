---
name: Staging change log timing
description: When to add project changes to JOLF Change log.
---

From now on, whenever this project is pushed to Git staging, record what changes were made in the JOLF Change log spreadsheet. Only do so when it has been pushed to Git.

**Why:** The user asked for this as an ongoing rule for this project.

**How to apply:** After confirming a staging push succeeded, add the changes from that push to the spreadsheet. Do not record uncommitted edits, local-only commits, preview changes, or a failed push as pushed changes. Work done or pushed outside this conversation will not be noticed automatically without separate automation.
