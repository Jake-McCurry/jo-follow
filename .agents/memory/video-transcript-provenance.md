---
name: Video transcript provenance
description: Distinguishing actual video transcripts from related JesusOnline study articles and empty caption responses.
---

Use an explicitly published transcript, verified spoken captions, or a matching video script supplied by the user for video transcripts. Do not substitute a related study article.

**Why:** JesusOnline's Total Life Discipleship library includes related articles that are substantially longer than the videos. YouTube caption requests can also return HTTP 200 with an empty body, so a successful request alone does not establish that a transcript was retrieved.

**How to apply:** Verify that the source is a transcript for the exact video and contains substantive text. Match sections in user-supplied script documents to the corresponding videos. If no verified transcript can be retrieved, identify the gap and request the script instead of inventing narration or relabeling a study article.
