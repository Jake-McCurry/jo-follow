------------------------------

   Its source URL and page heading are printed above the code box.
2. Click INSIDE the code box. Select All, then Copy.
3. Remove the previous XP content block from WordPress, not the theme shell.
4. Paste into the WordPress page Code editor as ONE complete wp:html block.
   Do not copy from a rendered page or paste into a Paragraph/Code block.

SCOPE AND WORDPRESS LIMITATIONS
------------------------------
Only main content is included. Header, navigation, footer, resume banners,
and the original app's backend are not copied.
All styling is inline. No React, scripts or external stylesheets are needed.
The HTML retains the source typography names: Source Sans 3 and Playfair
Display, with Arial/Georgia fallbacks. Identical typography requires those
fonts to be loaded by your WordPress theme/font settings.
Inline-only HTML cannot reproduce breakpoint/hover rules exactly or control
theme rules marked !important. Check the saved WordPress page, not only a
standalone preview. The exact text and original layout arrangement are
preserved; pixel-identical rendering in an unknown theme is not guaranteed.

Question, guide, video and contact URLs remain on the original Follow site.
"Save or Send this page" retains its visible label but uses an email link
instead of the JavaScript-powered native/clipboard sharing dialog, because
these snippets contain only HTML and inline CSS.

If the theme also prints a page title, use its per-page title settings to
avoid showing a duplicate. Do not hide the site's entire header.
If WordPress alters the snippet, inspect the saved Code editor HTML or share
the WordPress page URL before making further layout/content substitutions.
